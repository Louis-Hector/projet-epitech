### *SECOND_YEAR* :

- **[`TekSpice`](SECOND_YEAR/G-OOP-400-LIL-4-1-tekspice-6/README.md)** — Digital logic circuit simulator in C++, modeling electronic components (logic gates like AND, OR, XOR, logic inputs, RAM, flip-flops) using object-oriented graph management.

- **[`Arcade`](SECOND_YEAR/G-OOP-400-LIL-4-1-arcade-18/README.md)** — Modular gaming platform loading graphics libraries (`ncurses`, `SFML`, `SDL2`) and games (Pacman, Snake) dynamically at runtime via shared libraries (`dlopen`/`.so`).

- **[`Raytracer`](SECOND_YEAR/G-OOP-400-LIL-4-1-raytracer-5/README.md)** — 3D rendering engine built from scratch using ray-tracing techniques, featuring lighting models, material properties, shadow effects, ambient occlusion, and geometric reflections.
