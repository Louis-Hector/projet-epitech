- **Compilation System :** `Make`

## Project Structure

### *FIRST_YEAR* :

- **[`myLs`](FIRST_YEAR/B-PSU-100-LIL-1-1-myls-louis.hector)** — Recreation of the POSIX `ls` command-line utility, supporting file listing, permissions parsing, and flags (such as `-a`, `-r`, `-l`, `-R`).

- **[`myTop`](FIRST_YEAR/B-PSU-100-LIL-1-1-mytop-louis.hector)** — Real-time system monitoring tool inspired by `top`, developed using the `ncurses` library to display CPU, memory, and process statistics.

- **[`mySudo`](FIRST_YEAR/B-PSU-100-LIL-1-1-mysudo-louis.hector)** — Implementation of a privilege escalation mechanism replicating `sudo`, handling user permissions, password authentication, and execution with elevated rights.

- **[`Minishell1`](FIRST_YEAR/B-PSU-200-LIL-2-1-minishell1-louis.hector)** — Building a foundational UNIX command interpreter handling basic binary executions, environment variables (`env`, `setenv`, `unsetenv`), and built-in commands (`cd`, `exit`).

- **[`Minishell2`](FIRST_YEAR/B-PSU-200-LIL-2-1-minishell2-louis.hector)** — Extension of Minishell1 introducing advanced process control: I/O redirections (`>`, `>>`, `<`, `<<`), UNIX pipes (`|`), and command separators (`;`).

- **[`42sh`](FIRST_YEAR/B-PSU-200-LIL-2-1-42sh-louis.hector/README.md)** — Capstone shell project implementing a fully functional TCSH/BASH-like command interpreter featuring line editing, history, alias management, scripting support, and complex logical operators (`&&`, `||`).
