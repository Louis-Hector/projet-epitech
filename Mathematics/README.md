## MATHEMATICS :

Welcome to the **Mathematics** section, featuring several projects involving the practical application of mathematical concepts, linear algebra, signal analysis, and modeling.

---

## Technologies and Languages

- **Languages :** `Python`, `C`
- **Compilation System :** `Make`, `Python`

---

## Project Structure

### *FIRST_YEAR* :

- **[`101pong`](FIRST_YEAR/B-MAT-100-LIL-1-1-101pong-louis.hector)** — Calculation of vectors, velocity, and three-dimensional coordinates to predict the trajectory of a ball.

- **[`102architect`](FIRST_YEAR/B-MAT-100-LIL-1-1-102architect-louis.hector)** — 2D geometric transformation (rotations, translations, scalings, reflections) using matrix calculations.

- **[`103cipher`](FIRST_YEAR/B-MAT-100-LIL-1-1-103cipher-louis.hector)** — Encryption and decryption of text messages using matrix multiplication and inversion.

- **[`104neutrinos`](FIRST_YEAR/B-MAT-100-LIL-1-1-104neutrinos-louis.hector)** — Real-time statistical analysis (arithmetic/harmonic means, standard deviations, root mean squares).

- **[`105demography`](FIRST_YEAR/B-MAT-100-LIL-1-1-105demography-louis.hector)** — Demographic analysis and linear fitting (least squares method, correlation).

### *SECOND_YEAR* :

- **[`Interstonar`](SECOND_YEAR/G-CNA-400-LIL-4-1-interstonar-7)** — Geometric calculations of intersections and collisions between complex geometric volumes.

- **[`StoneAnalysis`](SECOND_YEAR/G-CNA-400-LIL-4-1-stoneanalysis-3)** — Audio signal processing (WAV files) and steganography (hiding and extracting hidden data).

#### Never commit object files, binaries, or virtual environments (`.venv`, `.env`).
#### Always run `make clean` or `make fclean` before pushing C code.
