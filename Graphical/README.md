## GRAPHICAL

Welcome to the **Graphical** section, featuring projects focused on 2D rendering, event handling, game loops, animation, and spatial collision algorithms using **CSFML** (C SFML).

---

## Technologies and Languages

- **Languages :** `C`
- **Compilation System :** `Make`
- **Libraries:** `CSFML` (C Simple and Fast Multimedia Library)

---

## Project Structure

### *FIRST_YEAR* :

- **[`myHunter`](FIRST_YEAR/B-MUL-100-LIL-1-1-myhunter-louis.hector)** — A 2D clicker/shooter game inspired by Duck Hunt, featuring a custom game loop, sprite animation, window events, score tracking, and a health/lives system.

- **[`myRadar`](FIRST_YEAR/B-MUL-100-LIL-1-1-myradar-louis.hector)** — Air traffic control simulation rendering aircraft and control towers in real-time, featuring 2D movement algorithms, hitboxes, and spatial partitioning (Quadtree) for optimized 2D collisions.
