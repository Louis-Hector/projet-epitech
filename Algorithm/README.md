## Project Structure

### *FIRST_YEAR* :

- **[`Organized`](FIRST_YEAR/B-CPE-110-LIL-1-1-organized-louis.hector)** — Implementation of a workshop inventory management system using dynamic linked lists and sorting algorithms in C.

- **[`Secured`](FIRST_YEAR/B-CPE-110-LIL-1-1-secured-louis.hector)** — Creation of a custom thread-safe hash table library featuring hash generation and collision handling.

- **[`Robotfactory`](FIRST_YEAR/B-CPE-200-LIL-2-1-robotfactory-louis.hector)** — Development of an assembler compiler that parses assembly code and outputs bytecode for Champions (`.cor` files).

- **[`Amazed`](FIRST_YEAR/B-CPE-200-LIL-2-1-amazed-louis.hector)** — Implementation of an optimized pathfinding algorithm (similar to BFS/Dijkstra) to move multiple robots through a maze with limited capacity.

- **[`Corewar`](FIRST_YEAR/B-CPE-200-LIL-2-1-corewar-louis.hector/README.md)** — Building a Virtual Machine (VM) simulating a battle arena where bytecode programs (Champions) execute concurrently to control the memory.

### *SECOND_YEAR* :

* *No network-related projects during the second year.*
