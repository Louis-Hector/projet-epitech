# Persona

**Persona** is a project from the module ***G4 - Prompt Engineering***. The goal is to create a personalisable AI newsletter

## Content

- [Summary](#summary)
- [Installation](#installation)
- [Project structure](#project-structure)

## Summary

Persona is a personalisable AI news aggregator with no UI. You interact with it via chatbot, and it will ask for or deduce your credentials, email address, topics of interest, and build a personnalized newsletter sent on an adaptable schedule.

If you want to follow the evolution of this project over time, we invite you to visit the :
